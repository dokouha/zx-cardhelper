# Z/X 卡牌助手

Z/X 卡牌查询 / 组牌 / 卡价工具。支持按颜色、类型、费用、力量、标记、种族、卡包筛选；游游亭实时卡价（同编号多罕贵度合并展示，3算/4算/5算换算）；组牌构筑与罕贵度造价计算。

支持 Android（APK）与 Windows（Electron）双平台，App 内置自动更新检测（GitHub Releases，可选更新）。

## 功能

- **卡牌查询**：多种条件组合筛选 + 搜索
- **卡价查询**：游游亭实时价格，多罕贵度切换，人民币换算
- **组牌**：主卡组 / 额外卡组构筑，罕贵度造价计算

## 下载

在 Releases 页面获取最新版本：

- `zx-cardhelper-vX.X.apk` — Android 安装包
- `Z-X-卡牌助手-vX.X.zip` — Windows 便携版（解压即用）
